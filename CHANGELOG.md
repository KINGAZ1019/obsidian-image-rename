# Changelog

## 1.0.0

- Prompt for a meaningful image name before saving pasted or externally dropped images.
- Preserve the originating note, attachment-folder preference, and matching embed.
- Add optional note-name prefixes and safe collision suffixes without overwriting files.
- Preserve image bytes and formats; handle cancel, batch input, note changes, and IME composition safely.
- Publish as a research-oriented fork of Paste Image Rename 1.6.1, retaining its MIT license, attribution, and template/settings code.
- Add English project metadata, documentation, a deterministic build, and 44 isolated tests.

The runtime interface remains in Simplified Chinese. The installation ID stays `research-image-rename` for compatibility.
